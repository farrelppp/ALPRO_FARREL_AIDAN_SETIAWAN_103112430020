PROGRAM terurut

    Kamus
    type <    
    bil1 : Integer
    bil2 : Integer
    bil3 : Integer
    >
    

    Algoritma    
    Input (Masukan angka:) 
    bil1 = masukan / 100                
    bil2 = (masukan MOD 100) / 10       
    bil3 = masukan MOD 10                

    
    Output (bil1 < bil2 DAN bil2 < bil3)

    END MULAI

END PROGRAM
